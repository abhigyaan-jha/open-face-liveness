# Models

Place browser-loadable ONNX and OpenCV assets here while developing locally.

The default manifest shape is:

```json
{
  "version": 1,
  "models": [
    {
      "id": "face-detector",
      "capability": "face-detector",
      "format": "onnx",
      "url": "/models/face-detector.onnx"
    }
  ]
}
```
